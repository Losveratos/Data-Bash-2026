# Data Bash 2026 · A Playbook for Generating IBCS-Inspired Reproducible Fabric Apps

Folien und Material zum Vortrag von Michael Tenner (Daten-WG by platformimpulse).
Slides and material for the talk at Data Bash 2026 (5 December 2026, online).

- **Folien / slides:** `index.html` im Browser öffnen. Deutsch ist Standard, Englisch mit `index.html?lang=en`
  oder Taste `l`. Tasten: → / Leertaste weiter, ← zurück, `o` Übersicht, `h` Foliennummer.
- **PDF:** `export/Data-Bash-2026-IBCS-Fabric-Apps-DE.pdf` und `-EN.pdf`, erzeugt mit `node tools/export.mjs both`
  (Playwright; prüft dabei Konsole, externe Abrufe und Überläufe je Folie).
- **Demo:** `demo/` (Live-Build mit der dwg cli, Ablauf in `demo/DEMO.md`).

Verwendet: [dwg cli](https://github.com/Losveratos/dwg-cli), ChartKitchen 1.58 und P&L Statement 1.8.4 byDatenWG,
MockupKitchen, fabscan. Alle Daten synthetisch. IBCS® ist eine eingetragene Marke des IBCS Institute; die Visuals sind
IBCS-inspiriert und nicht zertifiziert. Schriften selbst gehostet (SIL OFL 1.1), keine Abrufe von fremden Servern.
